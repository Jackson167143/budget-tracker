# Personal Budget Tracker

## Project Description

The Personal Budget Tracker is a simple web application that helps users record and track their daily expenses. It was created using HTML and CSS as part of a web development learning project.

## Features

- Add expense information using a form
- Enter expense name and amount
- Select an expense category
- Select the expense date
- View expenses in a table
- Includes 5 sample expenses
- User-friendly design
- Budgeting tips video
- Collapsible "How to use this tracker" section
- Table row hover effect

## Expense Categories

- Food
- Transport
- Rent
- Entertainment
- Other

## How to Use

1. Open `index.html` in a web browser.
2. Enter the expense name.
3. Enter the amount.
4. Select a category.
5. Select the date.
6. Click the **Add Expense** button.

The button will be connected to JavaScript in a later stage of the project.

## Future Improvements

JavaScript will be added in future weeks to make the Budget Tracker interactive. Users will be able to add, edit, delete, and calculate expenses automatically.
